# Generated Outputs

`sample_outputs.json` contains seven representative inference results from the
Personalized AI Study Companion pipeline.

Each result includes:

- The task and student query
- The generation instruction
- The retrieved source passage
- The retrieval similarity score
- A baseline output generated without retrieval
- A RAG output generated using the retrieved passage

The samples cover summaries, flashcards, multiple-choice questions, concept
explanations, definitions, selective permeability, and diffusion.

These are preliminary results. Retrieval is functioning, but some generated
answers remain incomplete or do not fully follow the requested format.
